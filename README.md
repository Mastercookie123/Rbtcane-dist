# RubertClient downloads

Client builds and automatic updates maintained by Mastercookie123.

1. Install 64-bit Java 21 and make sure the `java` command is available.
2. [Download RubertClient-Installer.zip](https://github.com/Mastercookie123/Rbtcane-dist/releases/latest/download/RubertClient-Installer.zip).
3. Extract it into a dedicated folder and double-click `RubertUpdate.bat`.

The first run downloads the client and starts it. Close the client and run the same file again to install future updates.

[All releases](https://github.com/Mastercookie123/Rbtcane-dist/releases)
